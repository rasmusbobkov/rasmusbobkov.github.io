# Estonian (et_EE) hunspell dictionary

`et.aff` and `et.dic` are the Estonian spell check dictionary from
[`wooorm/dictionaries`](https://github.com/wooorm/dictionaries)
(dictionaries/et, generated from http://www.meso.ee/~jjpp/speller),
committed verbatim so the spell check runs offline and identically on
every machine and in CI, with no system dependency.

License of `et.aff` and `et.dic`: LGPL-2.1. See
https://github.com/wooorm/dictionaries/blob/main/dictionaries/et/readme.md
for provenance.

Spelling problems in the dictionary itself should be reported upstream
(http://www.meso.ee/~jjpp/speller), not silently allowlisted here.
